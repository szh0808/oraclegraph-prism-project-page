❝ Abstract

严格的结构化生成仍是多模态大语言模型的关键瓶颈。监督微调（SFT）容易触及性能上限，而 DPO、GRPO、SimPO 等标量奖励方法将漫长的结构推理轨迹压缩为稀疏信号，导致策略层面的信号缺口与短输出偏置；普通自蒸馏甚至可能发生退化。为系统评测视觉、结构和关系联合推理，我们提出 OracleGraph：包含 10,000 页古籍文档、12 维诊断式 VQA 和结构幻觉分类体系的 2.5D 基准。进一步提出 PRISM，以图诊断报告（DGR）引导具有信息优势的回顾式教师，结合 Softmax 奖励加权聚合和长度归一化辅助偏好损失，稳定长序列结构生成。

在匹配秩与训练步数的实验中，PRISM 相比 Vanilla-SDPO 的 Graph Reward 提高 3.81 个百分点（p < 0.001）。相比 SFT，平均增益为 1.02 个百分点，尚未达到统计显著性（p = 0.12）；更明确的优势是跨种子稳定性：同分布与跨书籍 OOD 评测中的标准差分别约为 SFT 的 1/2.4 与 1/14。

01

研究背景与动机

读懂文字之后，还要读懂页面的结构。

古籍页面不是线性的文本：竖排正文、双行夹注、眉批、朱印与跨栏阅读顺序交织在一起。模型需要将这些视觉元素转换成符合 schema 的 JSON 图，明确“谁先读”“谁注释谁”以及“谁遮挡谁”。

稀疏奖励，丢失局部结构信号

一个标量难以定位长 JSON 中的节点、关系和拓扑错误。不可解析的输出会遇到零奖励断崖。

短输出偏置与自蒸馏退化

模型可能通过缩短响应规避解析风险；缺少图诊断与奖励感知的教师，也可能传递错误结构。

什么是 2.5D？

在二维坐标之外，每个节点带有离散遮挡层级 z ∈ {0, 1, 2, 3, 4}。例如，朱印所在层可高于墨色正文，使“文字识别”和“遮挡关系理解”能够分开评测。

结构幻觉，不能只看 OCR 准确率

论文建立了 30 余类结构幻觉分类，覆盖层级与阅读顺序、修改符号以及多模态遮挡。Graph-F1 采用节点与边类别的确定性宏平均 F1，检查生成图的拓扑一致性。

POLICY-REWARD INTEGRATED SELF-DISTILLATION

PRISM：让结构反馈进入策略优化

图诊断、奖励加权与长度归一化偏好约束共同稳定自蒸馏。

框架总览 论文 Figure 1

学生仅接收图像和提示；教师额外获得从真值图生成的 DGR。候选轨迹由 Graph-F1 评分，训练将密集的 token 级蒸馏与序列级偏好约束结合起来。

A

信息不对称与 DGR 教师

回顾式教师接收基于真值结构的诊断报告，获得拓扑与错误类型信息。盲学生仍需从图像中自主生成，信息差形成有方向的学习信号。

Hindsight Teacher
B

Softmax 奖励加权聚合

根据 Graph-F1 奖励为 rollout 轨迹分配权重，保留好坏候选的结构排序，降低错误拓扑在蒸馏梯度中的影响。

Reward-Weighted Aggregation
C

长度归一化辅助偏好损失

比较最佳与最差候选的归一化对数概率，扩大胜负轨迹间隔，并抑制因奖励稀疏而产生的短输出偏置。

Auxiliary Preference Loss
D

EMA 教师更新

教师通过指数移动平均跟踪学生，在保留结构锚点的同时缓和训练波动，为长序列学习提供持续、平滑的参考。

Exponential Moving Average

论文的核心结论

PRISM 显著缓解普通自蒸馏的退化，并在长序列结构生成中提高跨种子稳定性。收益主要体现在视觉关系和拓扑恢复。

局限与后续方向

相对 SFT 的均值增益未显著；OOD 同时含来源和密度变化；复杂空间诊断仍有较大提升空间。更高分辨率感知与纯来源变化评测有待进一步探索。
