❝ Abstract

从图像直接生成长 JSON 图谱，要求多模态大语言模型同时保持文本、对象与关系的完整性。本文以古籍页面为研究场景，分析策略层面的信号缺口、零奖励解析断崖和短输出偏置：标量奖励方法在匹配预算下停留在 SFT 附近，普通自蒸馏还可能退化。为研究这些问题，我们提出 OracleGraph：由程序共同生成页面与图谱标注的 10,000 页 2.5D 基准，配套 12 维诊断式 VQA。PRISM 将 DGR 条件化的回顾式教师、奖励加权蒸馏、长度归一化偏好损失和独立教师更新结合起来，改善长结构生成。

论文主表中，PRISM 相比 Vanilla-SDPO 的 Graph Reward 提高 3.81 个百分点（p < 0.001）；相对 SFT 的 +1.02pp 差异未达到统计显著性（p = 0.12）。新增分析将收益定位于低质量、长输出和复杂图谱页面，统一消融显示辅助偏好损失有助于减少截断和遗漏。在外部 GraphDoc 数据上重新训练后，Graph F1 提高 2.95pp。这些结果支持 PRISM 对被测结构生成任务的改进，尚不意味着普遍超越 SFT 或解决分布外迁移。

01

研究背景与动机

读懂文字之后，还要读懂页面的结构。

古籍页面不是线性的文本：竖排正文、双行夹注、眉批、朱印与跨栏阅读顺序交织在一起。模型需要将这些视觉元素转换成符合 schema 的 JSON 图，明确“谁先读”“谁注释谁”以及“谁遮挡谁”。

稀疏奖励，丢失局部结构信号

一个标量难以定位长 JSON 中的节点、关系和拓扑错误。不可解析的输出会遇到零奖励断崖。

短输出偏置与自蒸馏退化

模型可能通过缩短响应规避解析风险；缺少图诊断与奖励感知的教师，也可能传递错误结构。

什么是 2.5D？

完整 OracleGraph 在二维坐标之外记录离散遮挡层级 z ∈ {0, 1, 2, 3, 4}，描述朱印、正文和批注的层叠关系。已发布 LoRA 使用的 compact 输出保留内容节点与主要关系，不直接预测 z-index；完整本体与模型输出的覆盖范围应分别理解。

下载包与论文划分

ModelScope 发布包包含 5,000 页主集、4,500 页压力集，以及保存的全部 529 页 VQA（38,583 问），共 10,029 页。529 页是归档文件数量，不等于论文的 500 页诊断划分。主集另附固定的 4,900/100 训练与验证列表；复现 VQA 时需使用对应实验的选样及评分协议。

PRISM：让结构反馈进入策略优化

图诊断、奖励加权与长度归一化偏好约束共同稳定自蒸馏。

框架总览 论文 Figure 1

推理时，学生接收图像与提示；训练时，教师额外使用图结构反馈。候选的结构奖励决定蒸馏权重，长度归一化偏好项比较最佳与最差候选。迁移到其他图谱任务需要适配本体、匹配器和反馈内容。

A

信息不对称与 DGR 教师

回顾式教师接收基于真值结构的诊断报告，获得拓扑与错误类型信息。盲学生仍需从图像中自主生成，信息差形成有方向的学习信号。

Hindsight Teacher
B

Softmax 奖励加权聚合

根据 Graph-F1 奖励为 rollout 轨迹分配权重，保留好坏候选的结构排序，降低错误拓扑在蒸馏梯度中的影响。

Reward-Weighted Aggregation
C

长度归一化辅助偏好损失

比较最佳与最差候选的归一化对数概率，扩大胜负轨迹间隔，并抑制因奖励稀疏而产生的短输出偏置。

Auxiliary Preference Loss
D

EMA 教师更新

EMA 让独立教师缓慢跟踪学生。正式稿的匹配消融中，冻结教师与 EMA 的得分近似；两者差异未获统计确认，EMA 是默认更新方式。

Exponential Moving Average

移除辅助损失后，输出更长（1,371 → 1,441 tokens），截断更多（3.0% → 5.7%），严格 F1 更低。完整 PRISM 以更短输出恢复更多节点与关系。冻结教师与 EMA 的差异仅 0.0006，未获统计确认；移除 RW 的增量差异也仍需更多种子验证。

这是三种子消融子矩阵。ModelScope 发布的五种子权重均值为 pooled strict F1 0.5092，两者种子集合不同；不要把它们直接作组件差值。

论文的核心结论

PRISM 在被测设置中缓解普通自蒸馏退化，收益集中于长输出、复杂图谱和节点/关系完整性；在 GraphDoc 上重新训练也观察到正向增益。相对 SFT 的总体优势需要按各实验分别判断。

局限与后续方向

OracleGraph 主表相对 SFT 的均值差异未显著；严格 OOD 图谱恢复接近零；外部证据目前限于一个 GraphDoc 基准。训练需要结构监督或验证器，真实档案扫描的泛化仍需单独验证。
